### 🔴 通勤数据的三条口径红线

**1 ·「总体平均」是人口加权，「分规模平均」是算术平均，两者不可混用。**

以七普常住人口加权可复现报告值：

| 指标 | 报告 | 45 城算术平均 | 人口加权 |
|---|---|---|---|
| 45分钟以内通勤比重 | 77 | 79.53 ✗ | **77.05** ✓ |
| 60分钟以上通勤比重 | 12 | 10.38 ✗ | **12.15** ✓ |
| 单程平均通勤时耗 | 35 | 34.16 ✗ | **35.40** ✓ |
| 5公里以内通勤比重 | 52 | 53.47 ✗ | **51.76** ✓ |
| 轨道800米覆盖通勤比重 | 21 | 17.24 ✗ | **20.79** ✓ |

直接对 45 城取算术平均，45 分钟指标会**虚高 2.53 个百分点**。
（唯一例外：`45分钟公交服务能力占比` 算术 47.89 反而更接近报告的 48，见 `12_校验_总体均值口径.csv`。）

**2 · 指标有方向**，见 `07_指标字典.csv` 的「指标方向」列：

- `+1` 越大越好（4 项）：45分钟以内、5公里以内、轨道800米覆盖、45分钟公交服务能力
- `-1` 越小越好（4 项）：60分钟以上、平均时耗、平均距离、职住分离度
- `0` 中性（1 项）：**通勤空间半径是城市尺度的描述量，不是绩效指标**。
  不定义方向，地图配色和排名会把"北京通勤半径全国最大"呈现成"北京最好"。

**3 · 缺失不是 0。** 长表是 **1157 行，不是 9×3×45=1215**，差 58 行，每一条都有出处：

| 缺失 | 条数 | 原因 |
|---|---|---|
| 轨道800米覆盖 2022 全年 | 45 | 报告未给出 2022 年该指标逐城值 |
| 轨道800米覆盖 2023/2024 | 6 | 海口 / 银川 / 西宁未开通轨道 |
| 南通 2022 多项 | 6 | 报告留空 |
| 绍兴 / 洛阳 2022 时耗等 | 1 | 报告留空 |

把空值当 0 参与排名和均值，会让这三个城市"轨道覆盖全国倒数第一"。

## 五、轨道数据 `data/metro/`

| 文件 | 内容 | 行数 | 说明 |
|---|---|---|---|
| `stationInfo.csv` | 302 站：ID、**英文名**、经纬度、邻接站 | 302 | 中文名要你自己从 OSM 匹配 |
| `station_daily.csv` | 站点 × 工作日/周末 的日均进出站与三类客流 | **604** | = 302 × 2 |
| `station_hourly.csv` | 站点 × 日型 × 小时 的日均进出站 | **10268** | = 302 × 2 × 17 |
| `network_daily.csv` | 全网逐日总量 | 123 | 2017-05-01 ~ 08-31 |
| `od_pairs.csv` | 工作日日均 OD 前 4000 对 | 4000 | 占进站总量 38.6% |
| `od_top_by_origin.csv` | 每站前 15 大去向（保证每站都有数据） | 4530 | — |
| `osm_raw.json` | 54 条 relation（18 个线路 ref）：几何 / **官方线路色** / stop 坐标 | — | 你要从中筛线 |
| `osm_st3.json` | 728 个 element → 556 个唯一中文站名，478 条 `name:en` 对照 | — | 你要从中匹配中文名 |

### 字段

`in / out` 进出站总量。三分类由原数据集基于个体出行链识别，**完备且互斥**（三者之和 = 总量，实测差 0.0000%）：

| 前缀 | 含义 |
|---|---|
| `cin / cout` | 通勤（居住地 ↔ 就业地） |
| `hin / hout` | 居家其他（一端为居住地但非通勤） |
| `nin / nout` | 非居家（两端都不是居住地） |

`wd`：1 = 工作日，0 = 周末及节假日。`hr`：小时，6–22 共 17 档。`sid` 对应 `stationInfo.stationID`。

### 🔴 轨道数据的三条口径红线

**1 · 数据是 2017 年 5–8 月的。** 上海地铁此后扩至 523 站 / 906 公里，本平台反映 **14 线 302 站**的 2017 年格局。
这是目前唯一公开的站点级 OD 数据——上海地铁官方只发布全网日总量与季度 TOP 站点排名，不发站点级明细。
**所以这个平台做不了多年度同比**，改做工作日 vs 周末 + 123 天逐日序列。

**2 · 所有数值是日均**：工作日按 **87 天**、周末及节假日按 **36 天** 平均，**不是区间总量**。

**3 · 刷卡样本 ≠ 全口径客运量。** 工作日日均进站 651 万人次，低于官方口径（含单程票、二维码）。
适合分析**空间结构与相对差异**，不宜直接当绝对客运量引用。

```bash
python3 -m pip install pandas geopandas shapely streamlit
```

## 九、这门课到底在教什么

九个"看起来成功了"的坑。**它们全都不报错、肉眼也看不出来。**

| # | 坑 | 表现 | 在本课程中 |
|---|---|---|---|
| 0 | 合成数据混入 | 看不出来 | 已替你排除 |
| 1 | PDF 位图表格 | 解析器返回空表，不报错 | 已替你踩过，阶段 0 讲 |
| 2 | 口径不一致 | 均值对不上，差 2.53pp | **阶段 0 你自己复现** |
| 3 | 过滤条件漏数据 | 18 组而不是 19 组 | **阶段 0 你自己反算** |
| 4 | 指标方向 | 排名和配色反了 | **阶段 1 你自己定义** |
| 5 | resize 隐藏 canvas | ECharts 抛 InvalidStateError | **阶段 2 你会撞上** |
| 6 | OSM 只查 node | 295 站 vs 实际 523 站 | 已替你抓好，阶段 3 讲 |
| 7 | GCJ-02 坐标系 | 匹配大面积失败 | **阶段 3 你自己判定** |
| 8 | 时代错置 | 2017 数据配了 2021 线路 | **阶段 3 你自己发现** |
| 9 | 时间字段误读 | 1045 个"小时" | **阶段 0 你自己断言** |

抓出它们靠的不是更仔细地看代码，而是**每一步都设一个能证伪的验收断言**：
行数对不对、总量能不能反算、两种独立方法一不一致、和外部已知数字合不合。
