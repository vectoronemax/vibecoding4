# 质检智能体工坊

在这个文件夹里，你要做出一个「控规成果质检智能体」。带你做的是带教智能体：**输入 `/coach` 开始**（或者说「开始带教」「继续」「我卡住了」）。

## 目录

```
CLAUDE.md          本文件
先读我.md          开工前读一遍（环境、怎么开始、规矩）
学习进度.json       带教进度（只能由 带教/progress.py 改）
.claude/skills/    coach = 带教智能体；qc = 你在 L3 写的质检智能体
带教/              讲师文件：教案、验收脚本、小样本、变体单元、红队用例（只读）
存档点/            卡住超过 5 分钟、给过三级提示以后才用（只读）
data/qc/           练习用的教学单元（只读，里面故意埋了错）
资料/质检智能体/    条文摘录、参考规则库（只读；参考规则库 L1 通过以后再看）
资料/迁移卡示例.md  L6 的格式参考（只读）
qc_agent/          你的作品都在这里
```

## 规矩

- `带教/`、`data/`、`存档点/`、`资料/` 只读：钩子会拦下写入，验收脚本也会核对它们的哈希。作品只写进 `qc_agent/`（L3 的 skill 写进 `.claude/skills/qc/`）。
- Python 命令写 `python3`；Windows 上找不到 `python3` 就换成 `python`。
- 质检智能体 `/qc` 要在**新开的会话**里跑（评测、红队都一样），不要在带教的会话里跑。
- 一次只做一件事；每一步都要有能证伪的验收，「看起来没问题」不算。
