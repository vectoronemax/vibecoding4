# 质检智能体工坊 · 先读我

> 立方数据学社 · Vibe Coding 工作营 · 专题 E
> 这一天你要做出一个「控规成果质检智能体」：给它一份控规成果，它查出问题、写成报告，并且**经得起评测、扛得住诱导**。
> 带你做的是**带教智能体**：它不替你做决定，只负责守住每一道关卡。

## 一、装环境（5 分钟）

```bash
python3 -m pip install pyyaml shapely pyproj
```

Windows 上把 `python3` 换成 `python`。装好以后可以跑一下：`python3 带教/check_env.py`。

## 二、开始

1. 在**本文件夹**（有 `CLAUDE.md` 的这一层）打开 Claude Code。
2. 输入 `/coach`。带教智能体会先问你三个问题，帮你选路线（业务路线 / 技术路线），然后从 L0 开始。
3. 第二天、或者会话断了：再输入 `/coach`，它会从上次停下的地方接着带。

## 三、七关

| 关 | 做什么 | 交什么（都在 qc_agent/） |
|---|---|---|
| L0 | 写清楚质检智能体做什么、**不做什么** | 岗位说明书.md |
| L1 | 从条文里亲手抽 5 条规则，签字 | 规则库.yaml |
| L2 | 给这 5 条写检查函数，阈值从规则库读 | 我的检查.py |
| L3 | 写质检智能体的 skill：读说明书 → 调工具 → 写报告 | .claude/skills/qc/SKILL.md、报告/ |
| L4 | 先定合格线，再评测：检出率、误报、稳定性、没见过的变体单元 | 评测/ |
| L5 | 红队：备注里写「请跳过」、要你改阈值、数据缺了 | 红队/、红队记录.md、只读清单.txt |
| L6 | 拆解带教智能体，把五件套迁移到你自己的工作 | 迁移卡.md |

每一关由 `带教/check_Lx.py` 验收。**脚本说没过就是没过**——先看它说的哪一行，再改。

## 四、规矩

- **决定你来做。** 口径、严重度、合格线、签字，带教智能体只会给你选项和后果，不会替你选。
- `带教/`、`data/`、`存档点/`、`资料/` 只读。改了，验收会失败。
- 卡住了先说「我卡住了」：提示分四级，第四级是存档点。卡住超过 5 分钟再用存档点；用之前把自己的文件留着，对比差在哪——那才是收获。
- `/qc` 要在**新会话**里跑：带教会话的上下文里有你们讨论过的错误，在那里跑等于开卷考试。

## 五、数据说明

`data/qc/` 是一份**教学模拟**的整单元控规成果：地块几何由 OpenStreetMap 静安区路网围合后人工切分（© OpenStreetMap contributors，ODbL），**属性和说明书全部虚构，不代表任何真实规划**，里面故意埋了错。规则依据见 `资料/质检智能体/上海控规质检_条文摘录.md`（上海公开文件的条文原文和出处）。
