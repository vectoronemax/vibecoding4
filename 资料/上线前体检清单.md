# 上线前体检清单（专题 D · 上线之前：安全、授权与再分发）

上线就是把整个文件夹交给所有人。push 之前，按下面三步走一遍。

## 一、让脚本先扫（实操 1）

`scripts/prelaunch_check.py <要上线的文件夹>`：只报告、不改文件，结果写 `上线前体检.csv`，显示的值中间遮挡。

| # | 查什么 | 怎么查 | 常见误报 |
|---|---|---|---|
| 1 | 密钥 | `api_key = "…"`、`sk-…`、链接里的 `key=` 参数 | 示例代码里的假 Key（写成 `你的Key`） |
| 2 | 手机号 | 1 开头的 11 位数字 | **OpenStreetMap 的 osmid**（11 位编号）——看它在哪一列 |
| 3 | 身份证号 | 18 位、含出生日期 | 很少 |
| 4 | 邮箱 | 「名字 @ 域名」的样式 | JS 库文件头里作者的邮箱、模板里的占位邮箱 |
| 5 | 本机绝对路径 | `/Users/…`、`C:\Users\…` | 无：一律改成相对路径 |
| 6 | 大文件 | > 50 MB（GitHub 单文件上限 100 MB） | 无：大数据不进仓库，README 写下载地址和重建命令 |
| 7 | PDF / Word / Excel / PPT | 扩展名 | 自己做的海报、讲义——确认是自己的就行 |
| 8 | `.env`、`secrets.toml` | 是否写进了 `.gitignore` | 无 |

**命中不等于有问题，每一条都要人看一眼。** 判断方法：打开那个文件，看命中在哪一列、哪一段。

## 二、数据能不能公开（以各数据源官网当时的条款为准）

| 数据 | 来源 | 公开时要做什么 | 放进公开仓库 / 网页？ |
|---|---|---|---|
| 年鉴、七普、七普省际流动 | 国家统计局公开出版物 | 注明来源和年份 | 加工结果可以 |
| 45 城通勤指标 | 中规院《2025 年中国主要城市通勤监测报告》 | 注明出处；指标可以引用 | 指标可以，**报告 PDF 不放** |
| 路网、设施、建筑、街镇边界 | OpenStreetMap（ODbL） | 页面写「© OpenStreetMap contributors」；公开的衍生数据库同样按 ODbL | 可以，带署名 |
| 地铁客流、OD | MetroFlow（Scientific Data 2025，CC BY） | 署名 + 引用论文 | 可以，带署名 |
| 人口栅格 | GHSL、WorldPop（CC BY） | 署名 | 可以，带署名 |
| 行政区划边界 | DataV.GeoAtlas | 注明来源；对外的地图见第三节 | 课堂作品可以 |
| 北京百万 POI、静安餐饮 POI | 主讲人通过高德开放平台采集 | **只用于课堂学习** | **不放**：仓库和公开网页的 data.js 都不放 |
| 知识库里的期刊论文 | 版权归作者和期刊 | 课堂自己检索可以 | **不放**：公开的 RAG 只放题录和链接 |
| 北京 12345 年报 | 北京的聚合数 | 只能说北京；不能当成静安的诉求结构 | 聚合数可以，注明口径 |

个人信息：课程分发的数据里，电话一类的列已经整列删掉。你自己的数据如果有手机号、身份证、姓名——**用不到就删列，用得到就脱敏**，再进项目文件夹。

## 三、有地图的作品

- 放上公网、公众号、对外报告、展板，都算公开发布。
- 全国 / 世界范围的底图，用自然资源部「标准地图服务」下载的版本（带审图号），或按规定送审；国界线、省界、南海诸岛要完整。
- 只画研究区（某个区、某座城市）风险最小。拿不准就先问单位的测绘或宣传部门。以自然资源部当时的规定为准。

