# data/qc · 质检智能体练习数据（专题 E）

一份**教学模拟**的整单元控规成果，用来练「控规成果质检智能体」。地块属性和说明书是虚构的，里面**故意埋了错**——你的智能体要把它们找出来。

| 文件 | 内容 |
|---|---|
| `教学单元_地块.geojson` | 75 块地块：地块编号、街坊编号、用地代码、用地性质、混合比例、用地面积_m2、容积率、建筑高度_m、建筑密度_pct、绿地率_pct、规划状态、配套设施、备注 |
| `教学单元_街坊.geojson` | 22 个街坊：街坊编号、强度区（I–V 级）、高度分区（一级–五级） |
| `教学单元_单元边界.geojson` | 单元范围（含道路），算「单元总用地面积」用 |
| `教学单元_成果信息.json` | 区位、功能区域、地区类型、规划人口、坐标系、声明 |
| `教学单元_说明书.md` | 说明书节选（有数字，要和指标表对得上） |
| `教学单元_轨交站点.csv` | 单元周边 1.5 公里内的地铁站（OSM；含「在建」站） |

- 坐标：WGS-84（EPSG:4326）。量面积、算距离前先转 **EPSG:32651**（UTM 51N，单位米）。
- 来源：地块几何由 OpenStreetMap 静安区路网围合后人工切分（© OpenStreetMap contributors，ODbL）。**属性全部虚构，不代表任何真实规划**，仅课堂使用。
- 规则依据：`资料/质检智能体/上海控规质检_条文摘录.md`（上海公开文件的条文原文和出处）。
